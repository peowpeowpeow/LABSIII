# ПЗ №1. Middleware и шаблонизаторы — «ДонорКровь»

Платформа для донорства крови: запись на донацию, напоминания (уведомления), история донаций.
Express 5 + EJS. Вариант с хранением в файлах: записи — в `data/donations.json`, журнал запросов — в `logs/requests.log`.

## Запуск

```bash
npm install
npm start          # или npm run dev — перезапуск при изменении файлов
```

Открыть: http://localhost:3000 (гость) или http://localhost:3000/?auth=1 (авторизованный донор).

Требуется Node.js 18+.

## Маршруты

| Метод | Адрес | Назначение |
|---|---|---|
| GET | `/` | Список записей, статистика, фильтр `?status=planned\|done\|cancelled` |
| GET | `/item/:id` | Детальная страница записи, уведомление, история донора |
| GET | `/add` | Форма записи (только с `?auth=1`, иначе редирект на `/login`) |
| POST | `/add` | Проверка, запись в журнал, добавление в массив и файл, редирект на главную |
| GET | `/login` | Имитация входа |
| GET | любой другой | Страница 404 |

## Файлы и их сбои

| Файл | Нет файла | Сбой (нет доступа, папка вместо файла, файл занят) |
|---|---|---|
| `data/donations.json` | создаётся из `data/seed.json` | страница 500 с понятным описанием причины |
| `data/donations.json` с испорченным JSON | — | страница 500 «файл данных повреждён» |
| `logs/requests.log` | папка и файл создаются заново | сообщение в консоли и жёлтая полоса на странице; создание записи запрещено (страница 500) |

Как показать ошибку 500: запретить чтение файла `data/donations.json` (Windows: «Свойства → Безопасность → Запретить чтение»; Linux/macOS: `chmod 000 data/donations.json`) и обновить главную страницу. После возврата прав сайт снова работает без перезапуска.

## Ограничения

Все ограничения длины и диапазоны значений вынесены в `config/limits.json`. Размер тела запроса ограничен 10 КБ, у полей формы стоит `maxlength`.
