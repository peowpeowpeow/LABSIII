# ПЗ №1. Middleware и шаблонизаторы — «ДонорКровь»

Платформа для донорства крови: запись на донацию, напоминания (уведомления), история донаций.
Express 5 + EJS, данные хранятся в массиве в памяти и сохраняются в файл `data/donations.json`.

## Запуск

```bash
npm install
npm start          # или npm run dev — перезапуск при изменении файлов
```

Открыть: http://localhost:3000 (гость) или http://localhost:3000/?auth=1 (авторизованный донор).

Требуется Node.js 18+.

## Маршруты

| Метод | Адрес | Назначение |
|---|---|---|
| GET | `/` | Список записей, статистика, фильтр `?status=planned\|done\|cancelled` |
| GET | `/item/:id` | Детальная страница записи, уведомление, история донора |
| GET | `/add` | Форма записи (только с `?auth=1`, иначе редирект на `/login`) |
| POST | `/add` | Проверка, добавление в массив и в файл, редирект на главную |
| GET | `/login` | Имитация входа |
| GET | `/error-500` | Демонстрация ошибки 500 (синхронное исключение) |
| GET | `/error-500-async` | Демонстрация ошибки 500 (отклонённый промис) |
| GET | любой другой | Страница 404 |

Кнопки «Страница 404» и «Ошибка 500» есть в шапке сайта и на самих страницах ошибок.

## Middleware (порядок подключения в `server.js`)

1. `middleware/logger.js` — метод, URL, время запроса; после ответа — статус и длительность.
2. `express.static` — файлы из `public/`.
3. `express.urlencoded` — разбор данных формы (лимит 10 КБ).
4. `middleware/auth.js` — `auth` устанавливает `req.user` (Донор / Гость) по `?auth=1`; `requireAuth` защищает `/add`.
5. Маршруты.
6. `middleware/errorHandlers.js` — `notFound` (404.ejs) и `errorHandler` с 4 параметрами (500.ejs + лог с кодом ошибки).

## Проверки формы (`utils/validation.js`)

- обязательные поля не могут быть пустыми или состоять только из пробелов; лишние пробелы удаляются;
- ограничения длины: ФИО 5–60, телефон до 25, e-mail до 100, комментарий до 300 символов;
- ФИО — минимум два слова, только буквы, пробел и дефис внутри слова;
- числовые поля (возраст, вес, объём) — только цифры, значение ≥ 0, затем диапазон: возраст 18–65, вес 50–200 кг, объём по виду донации (кровь 200–450, плазма 200–600, тромбоциты 200–500 мл);
- значения списков (группа крови, резус, вид донации, центр, уведомление) сверяются со справочником;
- дата — реальная календарная, не в прошлом и не дальше 90 дней; время 08:00–16:00 с шагом 30 минут и не в прошлом для сегодняшней даты;
- телефон в формате +375 (XX) XXX-XX-XX, коды 25/29/33/44, приводится к единому виду;
- e-mail необязателен, но обязателен при уведомлении по e-mail; проверка формата;
- обязательное подтверждение отсутствия противопоказаний;
- запрет повторной записи одного телефона на одну дату.

Каждой записи присваивается уникальное «время создания записи» (с миллисекундами), оно выводится в списке и на детальной странице.
